# Шаблон политики обработки данных Travel Sync

Перед публикацией замените значения в квадратных скобках и согласуйте документ
с ответственным за персональные данные.

## Оператор

[Наименование юридического лица], [ИНН], [адрес], [email поддержки].

## Какие данные обрабатываются

- OAuth-токены установленного приложения Bitrix24;
- ключи API подключённых тревел-провайдеров;
- идентификаторы заказов, услуг и карточек Bitrix24;
- сведения о маршруте, стоимости, статусе и пассажире, выбранные
  администратором при сопоставлении полей;
- технический журнал синхронизации и обезличенные сообщения об ошибках.

Пароли, токены, номера документов, телефоны и email не должны попадать в
технический журнал. Исходные payload очищаются автоматически через
`DATA_RETENTION_DAYS`.

## Цель обработки

Перенос приобретённых командировочных услуг из Trivio, Aviasales for Business
и Smartway в выбранный смарт-процесс Bitrix24, обновление статусов и защита от
повторного создания карточек.

## Хранение и защита

- данные разных порталов разделяются по `member_id`;
- OAuth-токены и ключи провайдеров шифруются AES-256-GCM;
- публичный web-root ограничен каталогом `public/`;
- изменяющие запросы защищены подписанной сессией и CSRF-токеном;
- резервные копии шифруются и доступны только уполномоченным сотрудникам.

## Сроки

Технические payload и журнал хранятся [90] дней. Связка внешнего ID с карточкой
Bitrix24 хранится до удаления приложения, чтобы не создавать дубли.

## Удаление

При событии `ONAPPUNINSTALL` приложение удаляет OAuth-токены, ключи
провайдеров, настройки, курсоры, связи карточек и журнал соответствующего
портала. Запросы на досрочное удаление направляются на [email поддержки].

## Передача третьим сторонам

Приложение обращается только к Bitrix24 и тем тревел-провайдерам, которые
администратор портала подключил самостоятельно. Перечень инфраструктурных
поставщиков и регион размещения сервера указываются здесь: [перечень].

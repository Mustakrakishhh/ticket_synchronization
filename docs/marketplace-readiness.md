# Готовность Travel Sync к Bitrix24 Маркет

## Реализовано в коде

- разделение данных порталов по доверенному `member_id`;
- AES-256-GCM для OAuth-токенов и секретов провайдеров;
- MySQL и версионируемые миграции с обновлением существующей SQLite-схемы;
- защита от смешивания карточек разных смарт-процессов через `entity_type_id`;
- проверка `client_endpoint`, `app.info` и администратора до сохранения установки;
- открытие приложения не заменяет фоновый OAuth-токен токеном обычного пользователя;
- сессия связана с порталом и ID администратора, изменения защищены CSRF;
- обработчики `ONAPPUPDATE` и `ONAPPUNINSTALL`;
- база очереди поддерживает несколько worker без локального файлового lock;
- журнал действий администратора и очистка истории по сроку хранения;
- закрытый Bearer-токеном health-check в production;
- безопасный перенос данных SQLite → MySQL с резервной копией.

## Обязательные проверки перед отправкой на модерацию

1. Развернуть отдельную production MySQL-базу, включить ежедневные зашифрованные
   резервные копии и проверить восстановление копии.
2. Установить приложение минимум на два тестовых портала и доказать отсутствие
   пересечения настроек, токенов, очереди и журнала.
3. На тестовой версии приложения проверить установку, `ONAPPUPDATE`, повторное открытие
   другим администратором и `ONAPPUNINSTALL` с удалением данных только одного портала.
4. Проверить cron и несколько worker под параллельной нагрузкой, лимиты REST Bitrix24,
   backoff на HTTP 429/5xx и восстановление зависшей задачи.
5. Заполнить юридические реквизиты в политике обработки данных, указать реальный адрес
   поддержки, сроки ответа, регион хостинга и перечень инфраструктурных подрядчиков.
6. Подготовить карточку Маркета: описание, тарифы и ограничения, скриншоты, инструкцию
   установки, пользовательское соглашение и публичные ссылки на поддержку/политику.
7. Подтвердить договорные права на использование API Aviasales, Smartway и Trivio
   несколькими компаниями через опубликованное приложение.

Локальные тесты не заменяют проверку реального Marketplace OAuth и MySQL. До выполнения
этого списка версия является техническим кандидатом, а не гарантированно одобренным
приложением Маркета.
